Mundo Personajes

Descubre tus personajes favoritos

Explora el universo de tus series, películas y caricaturas favoritas a través de una colección de personajes de distintos mundos. Mundo Personajes es un sitio web que consulta APIs públicas para obtener y mostrar información e imágenes de los personajes de forma dinámica, ofreciendo una experiencia interactiva y organizada.

Este proyecto demuestra la integración de servicios externos mediante APIs y el uso de tecnologías web para presentar información de manera visual y accesible.
